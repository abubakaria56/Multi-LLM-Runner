Features

Built for comparing models, not juggling tabs

Pick the models, type the prompt once, and read the answers next to each other. Ask a follow-up and every model carries on its own conversation.

Parallel calls

Every selected model is called at the same time, so the slowest one never holds up the rest.

Answers as they land

Results stream to the page as newline-delimited JSON, so each column fills the moment its model finishes.

Memory per model

Each model keeps its own conversation. Reset one of them, a few, or all, without touching the others.

Timing and errors

Every answer shows how long it took. If a call fails, the error shows up in that model's column and the others carry on.

Retries built in

Timeouts, rate limits and malformed responses are retried with backoff, and <think> blocks are stripped from reasoning models.

Readable output

Markdown, highlighted code and LaTeX render properly in every column, and everything is sanitised first.

How it works

One request in, a stream of answers out

  1. You pick models and press Run. The React app posts the prompt and the model list to /api/chat-stream.
  2. One task per model. FastAPI starts an asyncio task for each model, using that model's own chat history.
  3. Answers stream back. Each result goes onto a queue and out to the browser as a line of JSON, in the order the models finish.

Quick start

Running in two terminals

You'll need Python 3.11+ with uv, Node.js 20+, and an OpenRouter API key.

1 · Backend
# add your OPENROUTER_API_KEY to .env
cd backend
cp .env.example .env
uv sync
uv run uvicorn app.main:app --reload --port 8000
2 · Frontend
# then open http://localhost:5173
cd frontend
npm install
npm run dev
